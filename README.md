# UniMate · يونيميت

Student community app for Jordanian universities: schedule, campus map, community, private messaging.

- `supabase/migrations` — database schema, security rules (RLS), triggers
- `supabase/tests` — security smoke tests
- `app` — mobile app (Expo / React Native)
- `admin` — admin panel

Secrets are never committed. See `.env.example` files.
